# 通勤キャリブレーター（仮称）

使うほど自分に合っていく、個人用の通勤プランナーです。

時刻表は誰でも手に入る公開データです。手に入らないのは「自分の数字」——家から改札まで実際に何分かかるか、7:37 の列車が普段どれくらい遅れるか、何分前に並べば何号車で座れるか。このプロジェクトは、その数字を通勤中にワンタップで記録し、次の計画に反映させる仕組みを中心に設計しています。

- 各区間の所要時間は「デフォルト値・自分の実測値・サンプル数」を持ち、状況別（一人／同行者あり／寄り道あり など）の幅で管理します
- 新しい値は自動で反映せず、本人の確認後に有効になります
- 観測者は「本人・他者（鉄道ファンの攻略記事、通勤者の投稿）・公的統計」の三種類。新しい土地では他者と公的データから始め、本人の観測が増えるにつれて置き換わります

現在は設計段階です。仕様は [`docs/SPEC.md`](docs/SPEC.md) にあり、実際の通勤ログ（駅名・日付・勤務先はマスク済み）を受け入れテストとして使っています。実装は記録機能（ステージ 1）から始めます。

個人の通勤ログと時刻表データはこのリポジトリに含めません。
